# Ignition

**Включай и выключай свой ПК прямо с телефона. Открывай Steam и Chrome одним нажатием.**

Ignition — это Android-приложение, которое удалённо управляет компьютером:

- **включает** ПК по сети (Wake-on-LAN);
- **выключает** его;
- **открывает** Steam и Google Chrome.

Работает из любой точки мира при условии, что ПК и телефон объединены в одну приватную сеть (VPN, например Tailscale).

## Быстрый старт (3 шага)

1. **Телефон:** установить приложение (см. «Что скачать»).
2. **ПК:** запустить агент и настроить Wake-on-LAN (разделы ниже).
3. **Приложение:** добавить ПК (кнопка **Add**) и заполнить форму.

---

## Шаг 1. ПК — запуск агента

1. Скачай `ignition-agent.exe` (ссылка в таблице выше) и положи в удобную папку.
2. Запусти его двойным щелчком.
3. Появится окно с надписью `Uvicorn running on http://0.0.0.0:8765` — агент работает.
4. При первом запуске Windows спросит про доступ к сети → **разреши для частных сетей**.

Проверка, что агент жив: открой в браузере на ПК
`http://127.0.0.1:8765/health` → должно вернуть `{"status":"ok"}`.

**Автозапуск (чтобы агент стартовал вместе с ПК):**
нажми `Win+R` → введи `shell:startup` → Enter → положи в открывшуюся папку ярлык на `ignition-agent.exe`.

> **Безопасность.** У агента пока нет пароля. Не открывай порт `8765` напрямую в интернет — доступ снаружи только через VPN.

## Шаг 2. ПК — настройка Wake-on-LAN (WoL)

WoL — это «магический пакет», который телефон шлёт в локальную сеть, и ПК включается. Настраивается один раз:

1. **BIOS/UEFI** — при загрузке войди (обычно `Del` или `F2`) и включи:
   - `Wake on LAN` / `Power On By LAN` / `Resume By LAN`;
   - **обязательно выключи** `ErP` / `EuP` (иначе сетевая карта обесточивается в выключенном ПК).
2. **Windows → Диспетчер устройств (`Win+X`) → Сетевые адаптеры → твой Ethernet-адаптер → Свойства:**
   - вкладка «Управление электропитанием»: разрешить устройству выводить ПК из ждущего режима;
   - вкладка «Дополнительно»: `Wake on Magic Packet` → **Enabled**.
3. **Отключить «Быстрый запуск» Windows:**
   Панель управления → Электропитание → «Действия кнопок питания» → «Изменение параметров, которые сейчас недоступны» → снять галочку «Включить быстрый запуск».
4. **Постоянный IP для ПК** — закрепи за MAC-адресом ПК постоянный адрес на роутере (DHCP Reservation), например `192.168.1.50`.

> WoL работает **только по проводу (Ethernet)** и **только в пределах локальной сети**.

---

## Шаг 3. Доступ из любой точки (VPN)

Поставь **Tailscale** ([tailscale.com](https://tailscale.com)) на ПК и на телефон, войди в один аккаунт. Узнай Tailscale-IP ПК (вида `100.x.y.z`) — это адрес для поля **Agent URL**:

```
http://100.x.y.z:8765
```

Теперь агент доступен из любой сети.

> **Важно про Wi-Fi/VPN и WoL.** Выключение и запуск Steam/Chrome идут по TCP и работают из любой точки. А вот магический пакет Wake-on-LAN — широковещательный, через обычный VPN он **не проходит**. Поэтому **включить** ПК можно только из дома (в той же локальной сети). Из другой страны — только если роутер умеет «WoL из интернета» или в домашней сети есть постоянно включённый мини-ПК-ретранслятор.

## Шаг 4. Подключение в приложении

Открой приложение → **Add** → заполни форму:

| Поле | Что вписать | Пример |
|------|-------------|--------|
| **Name** | любое имя ПК | `Studio PC` |
| **MAC address** | MAC сетевой карты ПК | `AA:BB:CC:DD:EE:FF` |
| **Broadcast address** | широковещательный адрес сети | `192.168.1.255` |
| **Agent URL** | адрес агента | `http://192.168.1.50:8765` |

Нажми **Save**. Приложение само проверит формат и не даст сохранить ошибку.

**Где взять значения:**
- **MAC** — в PowerShell: `getmac /v` (или `ipconfig /all` → «Физический адрес»).
- **Broadcast** — для сети `192.168.1.0/24` (маска `255.255.255.0`) это `192.168.1.255`; для `192.168.0.0/24` — `192.168.0.255`. Свою сеть смотри командой `ipconfig`.
- **Agent URL** — IP твоего ПК (локальный `192.168.x.x` или Tailscale `100.x.y.z`) и порт `8765`.

## Как пользоваться

Статус карточки ПК:

- 🟢 **ONLINE** — агент отвечает, ПК включён и доступен.
- ⚪ **OFFLINE** — ПК выключен или агент недоступен.
- **UNKNOWN** — идёт проверка.

Кнопки:

| Кнопка | Действие |
|--------|----------|
| **Wake** | включить ПК (магический пакет), доступна когда OFFLINE |
| **Shut down** | выключить ПК |
| **Steam** / **Chrome** | открыть приложение на ПК |
| **Refresh** | заново проверить статус |
| **Add** | добавить ещё ПК |
| **Edit** | изменить или удалить запись |

## Если не работает

**ПК не включается по кнопке Wake**
- Проверь настройки BIOS (ErP должен быть выключен), сетевой адаптер и «Быстрый запуск».
- Убедись, что **Broadcast address** — это адрес именно твоей сети.
- WoL работает только по проводу и только в локальной сети.

**Карточка всегда OFFLINE, хотя ПК включён**
- Открой на телефоне `http://IP-ПК:8765/health` — должно быть `{"status":"ok"}`.
- Проверь, что агент запущен и не блокируется файрволом Windows.
- Если работаешь через VPN — включён ли Tailscale на телефоне и ПК.

**Кнопки Shut down / Steam / Chrome не работают**
- Эти команды идут на агента: если он не запущен, они не сработают.
- Steam и Chrome должны быть установлены на ПК.

**Агент пишет «порт уже занят»**
- Порт `8765` занят другим процессом. Запусти агент на другом порту:
  ```powershell
  $env:IGNITION_PORT="8766"; .\ignition-agent.exe
  ```
  и укажи новый порт в Agent URL в приложении.
